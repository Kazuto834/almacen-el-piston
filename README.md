# Almacén El Pistón — Interfaz web

Interfaz visual estática para el sistema de gestión del Centro de Distribución y Almacén Automotriz **El Pistón**.

## Características

- Dashboard general.
- Búsqueda visual de inventario por SKU, nombre y categoría.
- Catálogo de productos.
- Consulta de zonas y ubicaciones del almacén.
- Órdenes de salida.
- Personal y productividad.
- Tres reportes operativos:
  - Stock por ubicación.
  - Eficiencia de recolección.
  - Ubicaciones vacías.
- Modales para simular altas/ediciones.
- Menú responsive para celular/tablet.
- Modo oscuro.
- Navegación mediante `#hash`, compatible con GitHub Pages.
- Sin backend y sin base de datos.

## Importante

Los datos que aparecen en pantalla son datos ficticios para demostrar el funcionamiento de la interfaz. El proyecto todavía no realiza operaciones reales sobre una base de datos.
